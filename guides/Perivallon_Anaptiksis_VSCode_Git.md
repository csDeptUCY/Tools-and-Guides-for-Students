# Περιβάλλον Ανάπτυξης: VS Code και Git

Κατά τη διάρκεια των σπουδών σας στο Τμήμα Πληροφορικής, συνιστούμε τη χρήση του Visual Studio Code (VS Code) ως το κύριο περιβάλλον ανάπτυξης για τη συγγραφή και εκτέλεση προγραμμάτων σε Java, C και Python (αρχεία Python και Jupyter Notebooks).

Το VS Code είναι ένα ελαφρύ αλλά ισχυρό γενικής χρήσης IDE, ευρέως διαδεδομένο τόσο στη βιομηχανία όσο και στον ακαδημαϊκό χώρο. Μέσω επεκτάσεων (extensions), παρέχει συμπλήρωση κώδικα, εργαλεία αποσφαλμάτωσης, ενσωματωμένο έλεγχο εκδόσεων και δυνατότητες διαχείρισης έργων.

Παράλληλα με τον προγραμματισμό, θα διαχειρίζεστε τον κώδικά σας χρησιμοποιώντας το Git, το πιο διαδεδομένο σύστημα ελέγχου εκδόσεων, αποθηκεύοντας τα repositories σας στο GitHub. Η χρήση Git και GitHub θα σας βοηθήσει να:

- Διατηρείτε ιστορικό της εξέλιξης της ανάπτυξής σας

- Αποθηκεύετε τον κώδικά σας με ασφάλεια online

- Εργάζεστε σε διαφορετικά χαρακτηριστικά χωρίς να χάνετε προηγούμενες εκδόσεις

- Μοιράζεστε την εργασία σας με διδάσκοντες και συνεργάτες

# 1. Εγκατάσταση VS Code

Για να δουλέψετε στον προσωπικό σας υπολογιστή, χρειάζεται να κατεβάσετε και να εγκαταστήσετε το VS Code.

Κατεβάστε το VS Code από: <https://code.visualstudio.com/download>

Επιλέξτε την έκδοση που αντιστοιχεί στο λειτουργικό σας σύστημα και ακολουθήστε τον επίσημο οδηγό εγκατάστασης:

- **Windows:** <https://code.visualstudio.com/docs/setup/windows>

- **macOS:** <https://code.visualstudio.com/docs/setup/mac>

- **Linux:** <https://code.visualstudio.com/docs/setup/linux>

Μετά την εγκατάσταση, ανοίξτε το VS Code και εγκαταστήστε τις κατάλληλες επεκτάσεις για τη γλώσσα προγραμματισμού σας μέσω του Extensions Marketplace, όπως περιγράφεται στο αντίστοιχο κεφάλαιο πιο κάτω.

# 2. VS Code & Java

Για να αναπτύξετε προγράμματα Java με το VS Code, πρέπει να έχετε εγκατεστημένα τόσο το VS Code όσο και το Java Development Kit (JDK). Ακολουθήστε τα ακόλουθα βήματα για τη ρύθμιση του προσωπικού υπολογιστή σας.

## Βήμα 1 — Εγκατάσταση Επεκτάσεων Java στο VS Code

Ανοίξτε το VS Code και εγκαταστήστε το Extension Pack for Java της Microsoft από το Extensions Marketplace. Αυτό το πακέτο επεκτάσεων παρέχει εργαλεία για:

- Μεταγλώττιση και εκτέλεση προγραμμάτων Java

- Αποσφαλμάτωση (debugging) Java εφαρμογών

- Συμπλήρωση κώδικα και πλοήγηση

- Υποστήριξη testing

## Βήμα 2 — Εγκατάσταση του Java Development Kit (JDK)

Εγκαταστήστε μια πρόσφατη Long Term Support (LTS) έκδοση του JDK από την Oracle:

- **Λήψη:** <https://www.oracle.com/europe/java/technologies/downloads/>

Επιλέξτε το πρόγραμμα εγκατάστασης για το λειτουργικό σας σύστημα και ακολουθήστε τις οδηγίες. Μετά την εγκατάσταση, επαληθεύστε ότι η Java αναγνωρίζεται ανοίγοντας ένα terminal και εκτελώντας:

```console
java -version
javac -version
```

Αν η εγκατάσταση έγινε σωστά, και οι δύο εντολές θα εμφανίσουν την εγκατεστημένη έκδοση. Η πρώτη επιβεβαιώνει το runtime (JRE), η δεύτερη τον μεταγλωττιστή (JDK). Μόλις εγκατασταθεί το JDK, το VS Code θα το ανιχνεύσει αυτόματα.

## Προτεινόμενη Δομή Φακέλων

Οργανώστε τις εργασίες σας όπως πιο κάτω για να αποφύγετε προβλήματα με την επέκταση Java:

1.  Δημιουργήστε έναν φάκελο εργασίας (π.χ. EPL131/) ως κεντρικό φάκελο για όλα τα projects σας.

2.  Μέσα σε αυτόν, δημιουργήστε έναν φάκελο για κάθε εργαστήριο ή εργασία:

```text
EPL131/
├── Labs/
│   ├── Lab1/
│   ├── Lab2/
│   └── Lab3/
└── Assignments/
    ├── Assignment1/
    └── Assignment2/
```

3.  Ανοίξτε στο VS Code μόνο τον συγκεκριμένο φάκελο εργαστηρίου, μην ανοίγετε τον κεντρικό φάκελο EPL131. Αυτό αποτρέπει την επέκταση Java από το να δημιουργεί ανεπιθύμητη δομή project.

4.  Δημιουργήστε τα αρχεία .java απευθείας μέσα στον φάκελο του εργαστηρίου:

```text
Lab1/
├── Hello.java
└── Exercise1.java
```

5.  Μην χρησιμοποιείτε δηλώσεις package στα προγράμματά σας:

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

6.  Μεταγλωττίστε και εκτελέστε το πρόγραμμα. Μπορείτε να χρησιμοποιήσετε το κουμπί Run στο VS Code ή να ανοίξετε το ενσωματωμένο terminal και να εκτελέσετε:

```console
javac Hello.java # μεταγλώττιση
java Hello       # εκτέλεση
```

# 3. VS Code & C

Το GNU Compiler Collection (GCC) χρησιμοποιείται συνήθως για τη μεταγλώττιση προγραμμάτων C σε περιβάλλον Linux. Σε αντίθεση με τα Linux, τα macOS και Windows δεν περιλαμβάνουν GCC εξ ορισμού. Στα macOS μπορεί να εγκατασταθεί GCC ενώ στα Windows υπάρχει και το MinGW σαν εναλλακτική λύση. Ακολουθήστε τα παρακάτω βήματα για τη ρύθμιση του προσωπικού υπολογιστή σας.

## Βήμα 1 — Εγκατάσταση Επέκτασης C/C++ στο VS Code

Ανοίξτε το VS Code και εγκαταστήστε την επέκταση C/C++ (όχι απαραίτητα το C/C++ Extension Pack) από το Extensions Marketplace. Αυτή η επέκταση παρέχει εργαλεία για:

- Συμπλήρωση κώδικα και έξυπνες προτάσεις

- Εργαλεία αποσφαλμάτωσης

- Πλοήγηση κώδικα και ανίχνευση σφαλμάτων

- Ενσωμάτωση με μεταγλωττιστές όπως GCC ή Clang

## Βήμα 2 — Εγκατάσταση του Μεταγλωττιστή GCC / MinGW

Χρήστες **macOS**:

1.  Εγκαταστήστε το Homebrew. Ανοίξτε το Terminal (μέσω Spotlight ή Launchpad) και εκτελέστε:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

2.  Εγκαταστήστε το GCC:

```bash
brew install gcc
```

3.  Επιβεβαιώστε την εγκατάσταση:

```console
gcc --version
```

Χρήστες **Windows:**

Ο μεταγλωττιστής GCC δεν είναι διαθέσιμος για μηχανές Windows αλλά υπάρχουν τρεις εναλλακτικές επιλογές:

**Α) Χρήση GCC που μπορεί να εγκατασταθεί μέσω του WSL (Windows Subsystem for Linux):**

Η προτεινόμενη προσέγγιση για Windows είναι η εγκατάσταση του WSL, που παρέχει ένα περιβάλλον Linux μέσα στα Windows το οποίο είναι πανομοιότυπο με τα τμηματικά εργαστήρια Linux.

1.  Εκκινήστε το Windows PowerShell ως Διαχειριστής (Administrator) και εκτελέστε:

```powershell
wsl --install
```

Αυτό ενεργοποιεί το WSL και κατεβάζει αυτόματα το Ubuntu. Στο τέλος, δημιουργήστε νέο χρήστη Linux (όνομα χρήστη και κωδικός).

2.  Ανοίξτε το VS Code και εγκαταστήστε την επέκταση WSL από το Extensions Marketplace. Αυτό επιτρέπει στο VS Code να ανοίγει φακέλους μέσα στο περιβάλλον Ubuntu και να χρησιμοποιεί εργαλεία Linux.

3.  Συνδέστε το VS Code με το περιβάλλον Ubuntu. Κάντε κλικ στο κουμπί 'Open a remote window' (\>\<) κάτω αριστερά στο VS Code και επιλέξτε Connect to WSL. Μετά την επιτυχή σύνδεση, κάτω αριστερά θα εμφανιστεί: WSL: Ubuntu.

4.  Εκκινήστε το Ubuntu terminal μέσα στο VS Code (Terminal → New Terminal) και εγκαταστήστε το GCC:

```bash
sudo apt update
sudo apt install build-essential
```

Το πακέτο `build-essential` εγκαθιστά το GCC, τον μεταγλωττιστή C/C++ και βασικά εργαλεία ανάπτυξης.

5.  Επιβεβαιώστε την εγκατάσταση:

```console
gcc --version
```

**B) Χρήση MinGW:**

Μια εναλλακτική λύση για Windows είναι η εγκατάσταση του MinGW (Minimalist GNU for Windows). Συνήθως περιλαμβάνει:

- gcc → compiler για C

- g++ → compiler για C++

- gdb → debugger

- make / mingw32-make → build tool

- βασικές βιβλιοθήκες και headers για Windows

Υπάρχουν οδηγίες [εδώ](https://code.visualstudio.com/docs/cpp/config-mingw) σχετικά με το πως να κατεβάσετε, εγκαταστήσετε και χρησιμοποιήσετε το MinGW μαζί με το VSCode. To MinGW υπάρχει και στις μηχανές των εργαστηρίων Windows του Τμήματος.

**Γ) Χρήση GCC που είναι εγκατεστημένος στις μηχανές Linux των εργαστηρίων του τμήματος.**

Μπορείτε να εγκαταστήσετε την επέκταση [Remote – SSH](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh) του VS Code και στη συνέχεια να συνδεθείτε απομακρυσμένα σε οποιονδήποτε υπολογιστή του εργαστηρίου 103 (103wsX.in.cs.ucy.ac.cy) ή του εργαστηρίου B103 (b103wsX.in.cs.ucy.ac.cy), όπου το X είναι ένας ακέραιος αριθμός από το 1 έως το 30. Αν δεν είστε συνδεδεμένοι στο δίκτυο του Τμήματος Πληροφορικής μέσω καλωδίου Ethernet ή μέσω του ασύρματου δικτύου WiFi του Τμήματος, θα πρέπει πρώτα να συνδεθείτε στο CS VPN.

Πηγαίνετε στο Extensions tab του VS Code, αναζητήστε το Remote – SSH και εγκαταστήστε το.

![Εγκατάσταση της επέκτασης Remote SSH](media/images/image1.png)

Πηγαίνετε στο Remote – SSH tab (κόκκινο τετράγωνο στην πιο κάτω εικόνα), και στη γραμμή του SSH, κάντε κλικ στο + για να προσθέσετε μια νέα απομακρυσμένη σύνδεση όπως για παράδειγμα:

```console
ssh username@b103wsX.in.cs.ucy.ac.cy
```

όπου το username είναι το username σας (που σας δόθηκε από το πανεπιστήμιο) και το X είναι ο αριθμός του απομακρυσμένου υπολογιστή που θέλετε να συνδεθείτε πάνω.

![Προσθήκη νέας απομακρυσμένης σύνδεσης SSH](media/images/image2.png)

Πατήστε Enter για να συνεχίσετε και, στη συνέχεια, πατήστε ξανά Enter για να αποθηκευτεί η σύνδεση στο αρχείο ρυθμίσεων SSH (*SSH config file*). Η νέα σύνδεση θα εμφανιστεί κάτω από το SSH. Πατήστε στο εικονίδιο με το βέλος δίπλα στη σύνδεση για να ξεκινήσει η σύνδεση με τον απομακρυσμένο υπολογιστή.

![Επιλογή απομακρυσμένης σύνδεσης](media/images/image3.png)

Όταν σας ζητηθεί να επιλέξετε το λειτουργικό σύστημα του απομακρυσμένου υπολογιστή, επιλέξτε Linux και στη συνέχεια πατήστε Enter.

![Επιλογή λειτουργικού συστήματος Linux](media/images/image4.png)

Ο απομακρυσμένος υπολογιστής θα σας παρουσιάσει το αποτύπωμα (*fingerprint*) του δημόσιου κλειδιού του και θα σας ζητήσει να επιβεβαιώσετε αν θέλετε να συνεχίσετε. Επιλέξτε Continue και το αποτύπωμα θα αποθηκευτεί στο αρχείο known_hosts. Στις επόμενες συνδέσεις δεν θα εμφανιστεί ξανά αυτό το μήνυμα, εκτός αν αλλάξει το κλειδί του απομακρυσμένου υπολογιστή.

![Επιβεβαίωση αποτυπώματος δημόσιου κλειδιού](media/images/image5.png)

Στη συνέχεια, θα σας ζητηθεί να εισαγάγετε τον κωδικό πρόσβασής σας (password), ο οποίος σας έχει δοθεί από το Πανεπιστήμιο.

![Εισαγωγή κωδικού πρόσβασης](media/images/image6.png)

Στο επόμενο σχήμα φαίνεται η ένδειξη κατάστασης του VS Code Remote SSH στην κάτω αριστερή γωνία του παραθύρου. Αυτό σημαίνει ότι το VS Code είναι αυτή τη στιγμή συνδεδεμένο στον απομακρυσμένο υπολογιστή Linux b103ws5.in.cs.ucy.ac.cy μέσω SSH.

![Ένδειξη ενεργής σύνδεσης Remote SSH](media/images/image7.png)

Τέλος, μεταβείτε στην καρτέλα Explorer και επιλέξτε Open Folder στον απομακρυσμένο υπολογιστή. Αν επιλέξετε να ανοίξετε έναν φάκελο που δεν υπάρχει, αυτός θα δημιουργηθεί αυτόματα από το VS Code.

![Άνοιγμα φακέλου στον απομακρυσμένο υπολογιστή](media/images/image8.png)

Όταν θελήσετε να αποσυνδεθείτε από τον απομακρυσμένο υπολογιστή, πατήστε στην ένδειξη κατάστασης του Remote SSH στην κάτω αριστερή γωνία του VS Code και επιλέξτε Close Remote Connection. Με αυτόν τον τρόπο θα τερματιστεί η σύνδεση με τον απομακρυσμένο υπολογιστή.

# 4. VS Code & Python / Jupyter

Για προγραμματισμό σε Python και εργασία με Jupyter Notebooks, συνιστούμε να εγκαταστήσετε πρώτα το Anaconda, μια ευρέως χρησιμοποιούμενη διανομή Python που περιλαμβάνει τον διερμηνέα Python, πολλές επιστημονικές βιβλιοθήκες, υποστήριξη Jupyter και το διαχειριστή πακέτων Conda.

## Βήμα 1 — Εγκατάσταση Επεκτάσεων Python στο VS Code

Ανοίξτε το VS Code και εγκαταστήστε τις παρακάτω επεκτάσεις από το Extensions Marketplace:

- **Python extension for VS Code** (της Microsoft)

- **Jupyter extension for VS Code** (της Microsoft)

Αυτές οι επεκτάσεις παρέχουν συμπλήρωση κώδικα, επισήμανση σύνταξης, αποσφαλμάτωση, εκτέλεση Python scripts και τη δυνατότητα δημιουργίας και εκτέλεσης Jupyter Notebooks (.ipynb) απευθείας μέσα στο VS Code.

## Βήμα 2 — Εγκατάσταση του Anaconda

- **Λήψη:** <https://www.anaconda.com/download/success>

Επιλέξτε την έκδοση για το λειτουργικό σας σύστημα και ακολουθήστε τις οδηγίες εγκατάστασης. Η εγκατάσταση περιλαμβάνει τον διερμηνέα Python, το περιβάλλον Jupyter Notebook, τον διαχειριστή πακέτων Conda και πολλές βιβλιοθήκες επιστήμης δεδομένων.

- **Παραδείγματα χρήσης Jupyter Notebooks στο VS Code:** <https://code.visualstudio.com/docs/datascience/jupyter-notebooks>

## Βήμα 3 — Επιλογή Διερμηνέα Python στο VS Code

Μετά την εγκατάσταση του Anaconda, πρέπει να ενημερώσετε το VS Code ποιον διερμηνέα Python να χρησιμοποιεί. Χωρίς αυτό το βήμα, το VS Code ενδέχεται να χρησιμοποιεί έναν διαφορετικό Python αντί για το Anaconda, προκαλώντας σφάλματα απουσίας βιβλιοθηκών.

1.  Ανοίξτε την Command Palette: Ctrl+Shift+P (Windows/Linux) ή Cmd+Shift+P (macOS).

2.  Πληκτρολογήστε και επιλέξτε: Python: Select Interpreter

3.  Επιλέξτε την καταχώρηση Anaconda Python (θα περιέχει 'anaconda' ή 'conda' στη διαδρομή, π.χ. ~/anaconda3/bin/python).

    **ΣΗΜΕΙΩΣΗ:** Μπορεί να χρειαστεί να επαναλάβετε αυτό το βήμα κάθε φορά που ανοίγετε νέο φάκελο project στο VS Code.

# 5. VS Code & Git

Ο έλεγχος εκδόσεων είναι ένα απαραίτητο εργαλείο για τη διαχείριση πηγαίου κώδικα και την παρακολούθηση αλλαγών κατά την ανάπτυξη λογισμικού. Το VS Code περιλαμβάνει ενσωματωμένη υποστήριξη Git, που σας επιτρέπει να εκτελείτε τις βασικές λειτουργίες ελέγχου εκδόσεων απευθείας από τον επεξεργαστή.

## 5.1 Εγκατάσταση Git στον Προσωπικό Υπολογιστή

Για να χρησιμοποιήσετε το Git στον προσωπικό υπολογιστή σας:

- **Windows:** Κατεβάστε και εγκαταστήστε από: <https://git-scm.com/download/win>

- **macOS:** Κατεβάστε από: <https://git-scm.com/download/mac> ή εγκαταστήστε μέσω Homebrew: brew install git

- **Linux (Ubuntu/Debian):** sudo apt update && sudo apt install git

Πλήρεις οδηγίες εγκατάστασης για όλες τις πλατφόρμες: <https://git-scm.com/book/en/v2/Getting-Started-Installing-Git>

## 5.2 Αρχική Ρύθμιση του Git

Πριν χρησιμοποιήσετε το Git, πρέπει να το ρυθμίσετε με το όνομα και τη διεύθυνση email σας. Αυτά τα στοιχεία προσδιορίζουν τον συγγραφέα κάθε commit. Η ρύθμιση αυτή απαιτείται τόσο στα τμηματικά εργαστήρια όσο και στον προσωπικό υπολογιστή.

Ανοίξτε ένα terminal και εκτελέστε:

```console
git config --global user.name "Το Όνομά σας"
git config --global user.email "email@example.com"
```

**ΣΗΜΕΙΩΣΗ:** Στα εργαστήρια Linux του Τμήματος, ο κεντρικός φάκελος χρήστη (home directory) είναι κοινός σε όλους τους σταθμούς εργασίας. Το αρχείο .gitconfig που δημιουργείται από αυτές τις εντολές θα είναι διαθέσιμο σε οποιονδήποτε υπολογιστή εργαστηρίου συνδεθείτε.

## 5.3 Χρήση Git στο VS Code

Μόλις εγκατασταθεί το Git, το VS Code το ανιχνεύει αυτόματα. Μπορείτε να διαχειρίζεστε τον έλεγχο εκδόσεων από τον πίνακα Source Control (Ctrl+Shift+G). Οι βασικές λειτουργίες περιλαμβάνουν:

- **Κλωνοποίηση (Clone):** Κατεβάστε ένα απομακρυσμένο repository (π.χ. από GitHub) στον τοπικό υπολογιστή σας.

- **Προσθήκη (Stage):** Επιλέξτε ποια τροποποιημένα αρχεία θα συμπεριληφθούν στο επόμενο commit.

- **Καταγραφή (Commit):** Αποθηκεύστε ένα στιγμιότυπο των αλλαγών σας τοπικά, με ένα περιγραφικό μήνυμα.

- **Αποστολή (Push):** Ανεβάστε τα τοπικά commits στο απομακρυσμένο repository στο GitHub.

- **Ανάκτηση (Pull):** Κατεβάστε και ενσωματώστε αλλαγές από το απομακρυσμένο repository.

- **Προβολή ιστορικού:** Περιηγηθείτε στο ιστορικό αρχείων και συγκρίνετε διαφορές μεταξύ εκδόσεων.

Περισσότερες πληροφορίες: <https://code.visualstudio.com/docs/sourcecontrol/overview>

## 5.4 Χρήση του Classroom 50

Οι εργασίες σας θα υποβάλλονται μέσω του GitHub αποθετηρίου (GitHub repository) που παράγεται από το Classroom 50. Η τυπική ροή εργασίας για κάθε εργασία είναι:

1.  Ανοίξτε τον σύνδεσμο πρόσκλησης (invitation link) που σας παρέχει ο διδάσκων. Συνδεθείτε με τον λογαριασμό σας στο GitHub (αν δεν είστε ήδη συνδεδεμένοι).

2.  Αποδεχτείτε (Accept) την εργασία. Το Classroom 50 θα δημιουργήσει αυτόματα ένα προσωπικό repository για εσάς. Πατήστε στον σύνδεσμο του repository σας και θα μεταφερθείτε σε αυτό.

3.  Αφού μεταφερθείτε στο repository της εργασίας σας, πατήστε στο πράσινο κουμπί που γράφει `<> Code` και αντιγράψτε το HTTPS URL του repository.

4.  Κλωνοποιήστε το repository στον τοπικό υπολογιστή σας. Στο VS Code, ανοίξτε την Command Palette (Ctrl+Shift+P), γράψτε/επιλέξτε Git: Clone και επικολλήστε το URL. Επιλέξτε έναν τοπικό φάκελο για αποθήκευση.

5.  Εργαστείτε στην εργασία σας μέσα στον κλωνοποιημένο φάκελο. Χρησιμοποιήστε την τυπική ροή Git: Pull → Stage → Commit → Push.

6.  Ανεβάζετε (push) την εργασία σας στο GitHub τακτικά. Ο διδάσκων θα βλέπει τα τελευταία commits που έχετε ανεβάσει.

    **ΣΗΜΕΙΩΣΗ:** Να χρησιμοποιείτε πάντα τον προσωπικό σας λογαριασμό GitHub, ώστε η συνεισφορά σας να αποδίδεται σωστά στο ιστορικό commits.

## 5.5 Χρήση του .gitignore

Δεν πρέπει όλα τα αρχεία ενός project να παρακολουθούνται από το Git. Compiled αρχεία, προσωρινά αρχεία και αρχεία ρυθμίσεων IDE δημιουργούνται αυτόματα και δεν χρειάζεται να αποθηκεύονται σε ένα repository. Για να αποτρέψετε το Git από το να παρακολουθεί τέτοια αρχεία, δημιουργήστε ένα αρχείο με όνομα .gitignore στον κεντρικό φάκελο του project σας.

- **Έργα Java:**

```gitignore
# Compiled class files και build artifacts
*.class
*.jar
*.war

# Build output directories
target/
bin/

# macOS metadata
.DS_Store

# VS Code workspace settings
.vscode/settings.json
```

- **Έργα C:**

```gitignore
# Compiled object files και executables
*.o
*.out
*.exe
a.out

# macOS metadata
.DS_Store

# VS Code workspace settings
.vscode/settings.json
```

- **Έργα Python:**

```gitignore
# Bytecode cache
__pycache__/
*.pyc
*.pyo

# Jupyter Notebook checkpoints
.ipynb_checkpoints/

# macOS metadata
.DS_Store

# VS Code workspace settings
.vscode/settings.json
```

Πλήρης συλλογή προτύπων .gitignore: <https://github.com/github/gitignore>

## 5.6 Καλές Πρακτικές

Για αναλυτικές καλές πρακτικές σχετικά με commit messages, στρατηγικές branching, code review και κριτήρια αξιολόγησης, ανατρέξτε στον **Οδηγό Καλών Πρακτικών GitHub**.

Κύρια σημεία:

- Κάνετε commit συχνά με περιγραφικά μηνύματα, κάθε ολοκληρωμένη αλλαγή αξίζει το δικό της commit.

- Κάνετε pull πριν ξεκινήσετε και push μόλις τελειώσετε.

- Μην αφήνετε την εργασία για την τελευταία στιγμή, η σταθερή πρόοδος αποτρέπει προβλήματα πριν την προθεσμία.

- Επικοινωνείτε με την ομάδα σας ώστε να μην εργάζεστε ταυτόχρονα στα ίδια αρχεία.

- Μην κάνετε ποτέ commit ευαίσθητες πληροφορίες (κωδικούς, API keys).

Αν έχετε ακολουθήσει τις οδηγίες αυτού του οδηγού και εξακολουθείτε να αντιμετωπίζετε προβλήματα, απευθυνθείτε στους διδάσκοντες ή τους βοηθούς εργαστηρίου.
