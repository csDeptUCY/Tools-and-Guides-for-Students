Βίντεο Οδηγιών

Σε αυτή τη σελίδα θα βρείτε σύντομα επεξηγηματικά βίντεο για τη χρήση του Git, του GitHub και του Classroom50, καλές πρακτικές οργάνωσης και συνεργασίας σε projects, καθώς και τα κριτήρια αξιολόγησης των εργασιών. Τα βίντεο παρουσιάζουν μόνο τις βασικές έννοιες. Για τις πλήρεις οδηγίες και κατευθύνσεις μελετήστε τους αντίστοιχους οδηγούς.

Git, GitHub & Classroom50

Γενική εισαγωγή στα εργαλεία που θα χρησιμοποιήσετε στο μάθημα: τι είναι το Git, τι είναι το GitHub και πώς λειτουργεί η πλατφόρμα Classroom50 για την παράδοση των εργασιών σας.

Εισαγωγή στο GitHub

Πρώτα βήματα στο GitHub: δημιουργία και δομή ενός repository, βασική πλοήγηση στο περιβάλλον, και πώς να αποφεύγετε χαοτικά και μη κατανοητά ονόματα αρχείων και φακέλων.

Καλές Πρακτικές Commit

Πώς να διατηρείτε ένα project οργανωμένο και ασφαλές μέσα από σωστές πρακτικές commit: πότε και πώς να κάνετε commit, τι περιλαμβάνει ένα καλό μήνυμα commit και πώς αποφεύγετε απώλεια ή αλλοίωση δεδομένων.

Κριτήρια Αξιολόγησης

Ανάλυση των κριτηρίων με τα οποία αξιολογούνται οι εργασίες: τι εξετάζεται, πώς κατανέμεται η βαθμολογία και ποια σημεία χρήζουν ιδιαίτερης προσοχής.

Συνεργασία στο GitHub

Πώς συνεργάζεστε αποτελεσματικά σε κοινό repository: branches, pull requests και κυρίως πώς αποφεύγονται τα merge conflicts όταν πολλά μέλη της ομάδας δουλεύουν ταυτόχρονα.
