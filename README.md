# Tools and Guides for Students

Αυτό το repository συγκεντρώνει τους οδηγούς εκπόνησης εργασιών, βίντεο με οδηγίες και υποστηρικτικό υλικό για τους φοιτητές του Τμήματος Πληροφορικής. Σκοπός του είναι να παρέχει σε ένα ενιαίο, εύκολα προσβάσιμο σημείο όλες τις απαραίτητες πληροφορίες για τη ρύθμιση του περιβάλλοντος ανάπτυξης, τη σωστή χρήση του Git/GitHub και τις καλές πρακτικές που αναμένονται κατά την εκπόνηση των εργασιών.

## Δομή Repository

```
guides/   → Οδηγοί εκπόνησης εργασιών (Markdown)
docs/     → Σελίδα προβολής βίντεο οδηγιών (GitHub Pages)
media/    → Βίντεο με κατευθυντήριες οδηγίες
```

## Οδηγοί

Στον φάκελο [`guides/`](./guides) θα βρείτε τους ακόλουθους οδηγούς:

- **[Περιβάλλον Ανάπτυξης: VS Code και Git](./guides/Perivallon_Anaptiksis_VSCode_Git.md)** — Οδηγίες εγκατάστασης και ρύθμισης του VS Code για Java, C και Python, καθώς και βασική χρήση του Git μέσα από το VS Code.

- **[Development Environment: VS Code and Git](./guides/Development_Environment_VSCode_Git.md)** — Installation and setup instructions for VS Code for Java, C, and Python, along with basic Git usage inside VS Code (English version).

- **[GitHub Best Practices](./guides/GitHub_Best_Practices.md)** — Καλές πρακτικές commit, στρατηγικές branching, οργάνωση repository, συνεργασία σε ομαδικές εργασίες, code review και κριτήρια αξιολόγησης χρήσης GitHub.

- **[Γενικές Οδηγίες Θεωρητικών Εργασιών και Διαγνωστικών](./guides/Odigies_Theoritikwn_Ergasiwn.md)** — Κανόνες μορφοποίησης και παράδοσης χειρόγραφων λύσεων, κριτήρια αξιολόγησης και οδηγίες για την ορθή αναφορά πηγών και εργαλείων ΤΝ.

- **[Γενικές Οδηγίες και Παράμετροι Αξιολόγησης Προγραμματιστικών Εργασιών](./guides/Odigies_Programmatistikwn_Ergasiwn-4.md)** — Κανόνες σχολιασμού και δομής κώδικα, ορθότητας λειτουργίας, επιτρεπόμενων τεχνικών, χρήσης GitHub/Classroom 50 και τα κριτήρια βαθμολόγησης προγραμματιστικών εργασιών.

## Βίντεο Οδηγιών

Σύντομα επεξηγηματικά βίντεο με τις βασικές έννοιες είναι διαθέσιμα μέσω της σελίδας [GitHub Pages](https://csdeptucy.github.io/Tools-and-Guides-for-Students/) του repository. Για τις πλήρεις οδηγίες, ανατρέξτε στους παραπάνω οδηγούς.
