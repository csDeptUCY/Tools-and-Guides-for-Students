# Εργαλεία και Οδηγοί για τους φοιτητές του Τμήματος Πληροφορικής του Πανεπιστημίου Κύπρου

Αυτό το repository συγκεντρώνει τους οδηγούς εκπόνησης εργασιών, σύντομα επεξηγηματικά βίντεο με οδηγίες και υποστηρικτικό υλικό για τους φοιτητές του Τμήματος Πληροφορικής. Σκοπός του είναι να παρέχει σε ένα ενιαίο, εύκολα προσβάσιμο σημείο όλες τις απαραίτητες πληροφορίες για τη ρύθμιση του περιβάλλοντος ανάπτυξης, τη σωστή χρήση του Git/GitHub και τις καλές πρακτικές που αναμένονται κατά την εκπόνηση των εργασιών.

## Επεξηγηματικά Βίντεο Οδηγιών και Εργαλείων

Σύντομα επεξηγηματικά βίντεο με τις βασικές έννοιες είναι διαθέσιμα μέσω της σελίδας [GitHub Pages](https://csdeptucy.github.io/Tools-and-Guides-for-Students/) του repository. Για πιο λεπτομερείς οδηγίες, ανατρέξτε στους πιο κάτω οδηγούς.
