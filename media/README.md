# Βίντεο Οδηγιών

Σε αυτόν τον φάκελο θα βρείτε, μεταξύ άλλων, σύντομα επεξηγηματικά βίντεο για τη χρήση του Git, του GitHub και του Classroom50, καλές πρακτικές οργάνωσης και συνεργασίας σε projects, καθώς και τα κριτήρια αξιολόγησης των εργασιών.

Το πρώτο βίντεο (**Git, GitHub & Classroom50**) είναι μεγαλύτερο σε διάρκεια και περιέχει συνοπτικά πολλά θέματα (τα τρία εργαλεία, commits, τρόπο εργασίας, οργάνωση αρχείων). Τα υπόλοιπα βίντεο είναι πιο μικρά και εξειδικευμένα, με καθένα εστιασμένο σε ένα συγκεκριμένο θέμα.

**Τα βίντεο παρουσιάζουν μόνο τις βασικές έννοιες. Για τις πλήρεις οδηγίες και κατευθύνσεις μελετήστε τους αντίστοιχους οδηγούς.**
